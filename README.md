Intent-Aware Style-Adaptive Response System
A chatbot that detects user intent (academic, technical, personal, entertainment, general) from natural language queries and generates factually correct responses in one of four adaptive styles: overconfident genius, nervous intern, sarcastic reviewer, or calm professor.
​


​

Features
Intent Classification: Rule-based keyword matching or ML model to categorize queries.
​

Style Adaptation: Same factual content delivered in distinct tones/personalities.
​

Interactive UI: Web/CLI interface with style selector and multi-style preview.
​

Factual Consistency: Core meaning preserved across all style variants.
